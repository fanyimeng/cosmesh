# 🚀 CosMesh 0.4.0｜一次重要更新

**⚠️ CosBase 已取消，今后统一使用 CosMesh。**
原 CosBase 的个人管理功能已融入 CosMesh。你的工作、历史记录、个人资料和关联信息全部保留，旧的独立 CosBase Skill 随升级备份并停用。

## 🧵 一件工作，一条 Thread

Thread 是持续积累一件工作的“工作串”：保存背景、进展、待办、讨论和成果。新会话优先续接已有 Thread，也可以按需新建、拆分、合并或归档。Thread 可以关联项目、目录和 Agent 会话，方便以后接着做。

## 🔒 私人 / 🌐 公开：现在只有这一个区分

- **私人 Thread**：默认新建为私人，供自己使用，可离线工作。
- **公开 Thread**：当前 Hub 的所有已认证用户都能读取，适合公开开展科研、写作和协作。指定收件人只决定通知谁。
- 个人资料、加密联系方式、目录和会话关联始终私人保存；附件需明确选择才上传。
- 私人 Thread 删除后进入回收站；公开 Thread 撤回后保留历史与引用。

## 📨 发消息，明确知道有没有发出去

关联私人 Thread 发送时，会首先醒目提示：

**⚠️ 尚未发送：关联的 Thread 为私人，对方看不到这条消息。**

默认引导你确认公开当前 Thread，再发送。公开 Thread 的消息会尝试提交；网络不可达时显示“待发送”，恢复连接后可重试。**服务器已接收与对方已查看分别显示。**

自己的工作记录写进自己的 Thread；回复、承接和交付沿原请求关联，成果保留作者和来源。

## 💬 继续通过自己的 Agent 使用

你可以直接说：

- “看看我的工作”“继续上次的研究”“记录本项目进展”。
- “公开这条 Thread，再发给某人”“收消息”“看看我和某人的对话”。
- “找一下以前的资料”“把这份报告附到公开 Thread”。
- “完善我的个人资料”“解释系统用法”“把这个问题反馈给开发者”。

私人工作和已缓存的公开内容可离线读写；联网后按需同步。资料与成果通过固定版本引用关联，方便追溯。

## ✨ 这次也让信息更简洁

标题使用完整短句，摘要尽量一句话；状态查询优先显示**当前状态、谁来处理、最新回应**，需要时再展开详情。
