# 🚀 CosMesh 0.4.7｜同一 Thread，跨设备接着做

**⚠️ 共享与消息接口已统一。连接新版 Hub 的用户请升级客户端，并新开 Agent 会话。**

- **跨设备续接**：同一 Thread ID，恢复内容并登记新设备、Agent 和目录。
- **分享更清楚**：私有／指定可见／全员可见，始终一位所有者；别人默认在线按需查看。
- **消息按人收录**：首次新来信自动建立无重名的私人按人 Thread；收发、回应、全文搜索与明确已读统一。列信不自动标已读。
- **更新只看变化**：索引按记录版本更新，可按上次快照获取变化清单，原文和文件按需读取。

**文件额度（单文件／单批／容量，含历史）**：个人 **5／10／30 GB**（本人合计）；对外 **2／5／15 GB**（每条Thread）。GB为十进制。科研数据、压缩包和未知后缀可存储，凭证继续过滤，文件仍需明确选择。

**原资料、配置和旧版保留。** 更新程序不自动公开私人内容。旧公开 Thread 由管理员备份迁移；客户端回退可读本地资料，旧Hub不能绕过新权限。中转没有端到端加密。
