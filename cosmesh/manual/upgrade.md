# 🚀 CosMesh 0.4.2｜让自己的多个 Agent 接着做同一件事

**✨ 新增个人共享：同机直接共用，跨设备私人接续，文件按需取回。**

你可以让同一台电脑上的多个 Agent 使用同一份工作台，也可以在自己的 Mac、另一台电脑和服务器之间接续工作。已有 Thread、历史记录、个人资料和项目关联继续保留。

## 🔒 三种使用方式，按需要选择

- **私人**：默认留在本地，可离线工作。
- **个人共享**：显式开启后，在本人账号的设备之间共享工作台；服务器按本人身份隔离存放。首次接入以整个工作台为单位，包含其中的私人记录、绑定和资源清单，请选择希望在本人设备间接续的工作台。
- **公开**：通过 Thread 的公开操作，让当前 Hub 的已认证用户读取，用于与他人协作。公开操作和消息发送仍需明确授权。

## 💻 同机轻松共用，跨设备按需传输

同机多个 Agent 共用同一工作台和原文件，无需复制或上传，本地资源引用没有传输大小限制。

跨设备同步由明确操作触发：默认同步工作记录和资源清单，文件需要另行选择上传，打开时按需下载并校验。不会因为更新软件而扫描目录或上传现有文件。小至中等资料支持私人中转；大文件、科研数据集和压缩包会经过大小与类型过滤，跳过时说明原因。传输支持续传，缓存不会覆盖项目原件。

**个人共享需本人主动开启；本次升级不会自动开启同步。私人中转依赖服务器的账号隔离，本期未提供端到端加密。**

## 💬 可以这样告诉你的 Agent

- “让这台电脑上的几个 Agent 共用这个工作台。”
- “把这个工作台接到我另一台电脑上，只同步记录。”
- “把选中的报告传到我的私人中转，另一台电脑需要时再取。”
