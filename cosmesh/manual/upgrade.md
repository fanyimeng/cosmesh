# 🚀 CosMesh 0.5.0｜同一 Thread 跨设备接续，项目摘要由你决定

- **接着做**　同一 Thread 保留各设备的 Agent、Project 和多个目录。补关联时，只有当前设备的宿主确认了 Session 归属，才能绑定 Project。
- **选择分享**　用 `thread associate ID` 预览，再在设置可见范围时加 `--share-projects`，分享 Agent、项目类型与显示名称。设备、目录和 Session 仅本人可见。旧快照沿用原权限，私人变动不会刷新共享版本。
- **升级后新开 Agent 会话**，即可加载新版 Skill。DSH Connector 0.1.2 可按需单独更新。原资料和旧版回退入口均保留。
