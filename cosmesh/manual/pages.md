# 本人工作页与在线来源

thread page --ready --json 读取本人本地工作页；已知工作可指定 ID，--level brief/status/index 选择深度。页面由已保存记录派生，包含名称、介绍、进展与私人关联，更新中状态如实展示。私人目录和项目映射不进入他人的在线视图。

查看他人的当前可见内容使用 thread browse；按人定向追踪使用 thread track 或普通 show/context/continue 打开追踪 Thread。服务器按当前权限返回清单，离线仅展示本人记录，已保存旧页面不能证明当前访问权限。

旧公共 Git 成品服务在迁移后关闭。本地历史缓存保留，当前 Thread 原文与历史通过受限在线接口读取，不自动拉整库。
